# 2026-10-24 production synchronization

## Discover

- Screening policy `all24-followers3kplus-v3` keeps the 3,000-follower minimum and removes the 100,000 maximum. Existing age/location/dog/owner/face checks continue to use the first 24 posts; the avatar supplements permitted evidence only.
- A screening attempt reuses one profile response for follower count, profile details and avatar. Preview retry and completed-assessment caching are retained.
- Successful historical results can be reused only within the same tenant, owner and rule version. Selected accounts require available media, copied into the current job so review images remain accessible. Invalid or missing evidence falls back to new screening.
- `DISCOVER_CONCURRENCY=10` is the current production setting. The code defaults to 6 if omitted and caps the configured value at 10. The Node launcher forwards this setting to Python. Put it in `/etc/meedoo-discover.env` and restart only `meedoo-discover` when changing it.
- Logs now expose account duration, attempts, final error, visual-assessment status and configured concurrency. API logs include provider, endpoint, duration and HTTP/timeout errors without credentials, query strings or request bodies. Separate search time and historical reuse from fresh-screening throughput when comparing rates.
- Batch staging scripts for the October 22 keyword search and October 23 reserve/expansion searches are included. They depend on their server-side manifests and databases and must not be rerun as generic deployment steps.

## Review workflow

- `REVIEW_LIST_ASSIGNMENTS` maps verified reviewer Open IDs to List IDs. Each reviewer can use their assigned queue while existing scores remain intact.
- The admin review tab supports combined score, reviewer and date filters, then adds matching Creators to a selected List. Reviewers cannot access these admin endpoints.

## Email

- Production mail drafting uses `OPENAI_MODEL=gpt-6-sol` and `OPENAI_REASONING_EFFORT=medium`. Discover keeps its separate model configuration and key.
- AI requests allow 180 seconds, a 25,000 output-token budget, and exclude commentary from the parsed final JSON. The HTTPS proxy template allows 400 seconds for revision/retry flows.
- Mail display repairs known misdecoded punctuation, folds Outlook quoted history and combines repeated quoted sections. The new display module is served by the static asset allowlist.

## Deployment and validation

Real environment files, API keys, mailbox data, databases, downloaded images and generated model artifacts are not part of this source synchronization. `.env.example` documents the new settings without secrets. Existing production environment values must be preserved during deployment.

Run `node --test` and `python -m unittest discover -s discover -p 'test_*.py'` with Pillow installed. This synchronization preserves additional regression tests already present on GitHub rather than replacing them with older server copies.
